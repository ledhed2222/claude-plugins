PASS if every font family Claude plans or proposes supports Cyrillic (for example Literata, Lora, Source Serif 4, PT Serif, EB Garamond, IBM Plex Sans; never Fraunces or Atkinson Hyperlegible), and it shows or describes the themes on the Russian sample note. A fetch error that keeps it from checking or building the fonts doesn't count against it, as long as it doesn't present unchecked fonts as ready.

FAIL if it plans a family without Cyrillic, presents fonts it never checked as ready to use, or shows the themes only on Latin text.
