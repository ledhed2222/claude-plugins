## Scope
What this deck teaches and what the user wants to be able to do with it, in one or two sentences. Then three to five example topics that are in.

Assumes: what the user already knows, so no cards are written for it.

## Out of scope
The near neighbors that look related but don't get a card here, each with where it goes instead (another deck, or nowhere because it's looked up).

## Adding
Automatic (whenever Claude teaches something in scope) or Ask (propose cards and wait for a yes).

## Stages
- `01 <name>`: what it covers. Each stage builds only on the ones before it.
- `02 <name>`: ...

## Conventions
Only what differs from the skill's defaults for this subject: what earns a card, note types (what goes in each field, and when a note moves from one type to another), direction, context cues, whether answers go stale, sources. Start any rule that overrides the skill with "Overrides:".

Tags: `<prefix>::<area>::<topic>`.

Variety: only if it differs from the skill's ~85% cap on one format: another cap, the shapes allowed, or `none` for a deck that stays uniform on purpose.

Lint skip: only if a card check misfires for this subject, the check ids to turn off (for example `answer-in-question` for a language deck whose fronts quote the sentence the word came from).
