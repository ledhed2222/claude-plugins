# claude-plugins

ledhed2222's Claude Code plugin marketplace.

```
/plugin marketplace add ledhed2222/claude-plugins
```

| Plugin | Description |
| --- | --- |
| [rememberthemilk](plugins/rememberthemilk) | Connects Claude Code to [Remember The Milk's](https://rememberthemilk.com) hosted MCP server (unofficial). Requires a Remember The Milk Pro account. |
| [ankimcp](plugins/ankimcp) | Connects Claude Code to an Anki MCP server: the local AnkiMCP add-on or a self-hosted [anki-sync-mcp](https://github.com/ledhed2222/anki-sync-mcp) (unofficial). |
| [anki-notes](plugins/anki-notes) | Turns what Claude teaches you into staged Anki flashcards, through either of ankimcp's servers. Needs ankimcp. |
