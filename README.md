# claude-plugins

ledhed2222's Claude Code plugin marketplace.

```
/plugin marketplace add ledhed2222/claude-plugins
```

| Plugin | Description |
| --- | --- |
| [rememberthemilk](plugins/rememberthemilk) | Connects Claude Code to [Remember The Milk's](https://rememberthemilk.com) hosted MCP server (unofficial). Requires a Remember The Milk Pro account. |
| [ankimcp](plugins/ankimcp) | Connects Claude Code to [Anki's](https://apps.ankiweb.net) local MCP server (unofficial). Requires Anki running with the AnkiMCP add-on. |
| [anki-notes](plugins/anki-notes) | Turns what Claude teaches you into staged Anki flashcards, with a Remember The Milk inbox for cards drafted away from Anki. Needs ankimcp and rememberthemilk. |
